# Bing Rewards Auto Search

Userscript de Tampermonkey que automatiza búsquedas diarias en Bing para acumular puntos de Microsoft Rewards. / Tampermonkey userscript that automates daily Bing searches to collect Microsoft Rewards points.

## Español

**Qué hace:** ejecuta automáticamente búsquedas en Bing (con retrasos humanizados) para ayudarte a completar los puntos de búsqueda diarios de Microsoft Rewards.

**Características:**
- Panel de control multiidioma.
- Lista de palabras clave personalizable y persistente.
- Retrasos aleatorios entre búsquedas para un comportamiento más natural.

**Instalación:**
1. Instala [Tampermonkey](https://www.tampermonkey.net/).
2. Abre el instalador: [bing-rewards-auto-search.user.js](https://github.com/g31w0fw0rld/bing-rewards-auto-search/raw/main/bing-rewards-auto-search.user.js) (también disponible en GreasyFork y OpenUserJS).

**Sitio:** `bing.com`

> ⚠️ Automatizar la actividad puede infringir los términos de Microsoft Rewards. Úsalo bajo tu propio riesgo.

## English

**What it does:** automatically runs Bing searches (with humanized delays) to help you complete Microsoft Rewards daily search points.

**Features:**
- Multi-language control panel.
- Customizable, persistent keyword list.
- Randomized delays between searches for more natural behavior.

**Install:**
1. Install [Tampermonkey](https://www.tampermonkey.net/).
2. Open the installer: [bing-rewards-auto-search.user.js](https://github.com/g31w0fw0rld/bing-rewards-auto-search/raw/main/bing-rewards-auto-search.user.js) (also on GreasyFork and OpenUserJS).

**Site:** `bing.com`

> ⚠️ Automating activity may violate Microsoft Rewards terms. Use at your own risk.
